# Velora Electronics

Velora Electronics is a full-stack e-commerce web application developed with Java and Spring Boot. The application allows customers to browse an electronics catalog, search and filter products, manage their shopping cart, and complete purchases through a checkout process.

The application uses Thymeleaf for server-side rendered web pages and MySQL for relational data storage. It includes customer account management, product catalog functionality, shopping cart and order management, payment methods, gift cards, and other features commonly found in an e-commerce platform.

## Features

* **Home Page**

    * Promotional content and featured products.
    * Category navigation for commonly browsed product types.
    * Featured products selected from the available inventory.


* **Product Catalog**

    * Browse a catalog of electronics products.
    * View detailed product information and specifications.
    * Browse products by category and brand.
    * Sort products by price.


* **Product Search and Filtering**

    * Search for products by name and category-related keywords.
    * Filter products by category and brand.
    * Combine search and filtering options to find specific products.


* **Customer Accounts**

    * Create and manage customer accounts.
    * Secure customer authentication and login.
    * Update profile information.
    * Change account passwords.
    * Manage saved addresses.


* **Shopping Cart**

    * Add products to a shopping cart.
    * Adjust product quantities.
    * Remove products from the cart.
    * View an order summary before checkout.


* **Checkout**

    * Select a shipping address.
    * Select a shipping speed.
    * Apply gift cards and coupon codes.
    * Select an existing payment method or enter payment information during checkout.
    * Review order details before completing a purchase.


* **Payment Methods**

    * Save payment cards to a customer account.
    * Add, edit, and manage saved payment methods.
    * Validate payment card information.


* **Gift Cards**

    * Apply gift cards during checkout.
    * Validate gift card codes and available balances.
    * Apply gift card balances toward purchases.


* **Orders**

    * Place orders through the checkout process.
    * View previous orders from the customer account.
    * View detailed information about individual orders and their products.
